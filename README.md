# Godot Sandbox

A personal collection of reusable components and tools built in Godot 4.7 to speed up game development and prototyping.

## Contents

* **Beatmap Generator**
  * **Description:** An editor tool (`@tool`) for automatically generating rhythm game beatmaps in JSON format from an audio file.
  * **Location:** `BeatmapGenerator/`
  
  📄 [**Beatmap Generator Guide (HOWTOUSE.md)**](BeatmapGenerator/HOWTOUSE.md)

* **Music & Audio Managers**
  * **Description:** A lightweight sound and background music system with node pooling, 2D positional support and sound cooldowns.
  * **Location:** `Music&AudioManagers/`
  
  📄 [**Music & Audio Managers Guide (HOWTOUSE.md)**](Music&AudioManagers/HOWTOUSE.md)
